# ระบบจัดการร้านก๋วยเตี๋ยว

สิ่งที่ใช้งานได้

ลูกค้าสั่ง (สั่งกี่รอบก็ได้ ทุกรอบเข้าบิลเดียวของโต๊ะ) → พนักงานกด ยืนยัน → ทำเสร็จแล้ว → เสิร์ฟแล้ว
ลูกค้ากด เรียกเก็บเงิน (หรือพนักงานเปิดเอง) → ปุ่ม บิล / เก็บเงิน บนหน้าร้านจะกะพริบพร้อมเสียงเตือน
กด บิล / เก็บเงิน → เลือกโต๊ะ → เห็นทุกรอบที่สั่ง (ยกเลิกออเดอร์ที่สั่งผิดได้) → ใส่ส่วนลดถ้ามี
PromptPay: ให้ลูกค้าสแกน QR ตามยอด → ดูเงินเข้าในแอปธนาคารของร้าน → กด ได้รับเงินแล้ว
เงินสด: กรอกเงินที่รับ (หรือกดปุ่มลัด) ดูเงินทอน → กด รับเงินสด
ระบบแสดงใบเสร็จให้พิมพ์ได้ โต๊ะว่างทันที
มีออเดอร์ที่ รอยืนยัน ค้างอยู่ในบิล ระบบจะไม่ให้เก็บเงิน ต้องกดยืนยันหรือปฏิเสธก่อน
ลูกค้าที่สั่งกลับบ้านผ่านพนักงาน จะได้บิลแยกของตัวเอง เก็บเงินจากปุ่มเดียวกัน


## วิธีติดตั้ง

### 1) สร้างฐานข้อมูลที่ Supabase (ฟรี)
1. สมัคร https://supabase.com แล้วกด New project (เลือก region Singapore ใกล้ไทยที่สุด)
2. ไปที่ **SQL Editor** → New query → คัดลอกเนื้อหาใน `schema.sql` ทั้งไฟล์วาง → กด **Run**
3. ไปที่ **Project Settings > API** คัดลอก `Project URL` และ `anon public key`
4. เปิด `config.js` แล้วแทนค่า `SUPABASE_URL`, `SUPABASE_ANON_KEY` และ `SHOP_NAME`

### 2) สร้างบัญชีพนักงาน
1. ใน Supabase ไปที่ **Authentication > Users > Add user**
2. ใส่อีเมลและรหัสผ่าน (ติ๊ก Auto Confirm User) แล้วใช้ล็อกอินที่ `staff.html`
3. ใน **Authentication > Sign In / Providers > Email** ควรปิด "Allow new users to sign up" เพื่อไม่ให้คนนอกสมัครเองได้

### 3) ทดสอบในเครื่อง
เปิดโฟลเดอร์นี้ใน terminal แล้วรัน `python3 -m http.server 8000`
- หน้าลูกค้า: http://localhost:8000/order.html?t=1
- หน้าร้าน: http://localhost:8000/staff.html

(ต้องเปิดผ่านเซิร์ฟเวอร์แบบนี้ ดับเบิลคลิกไฟล์ตรงๆ อาจใช้ไม่ได้)

### 4) นำขึ้นเว็บจริง
อัปโหลดทั้งโฟลเดอร์ไปที่ GitHub Pages, Netlify หรือ Vercel (ฟรีทั้งหมด ได้ HTTPS)

### 5) ทำ QR ติดโต๊ะ
สร้าง QR จากลิงก์ `https://โดเมนของคุณ/order.html?t=1` ถึง `t=6` (เลขตาม id ในตาราง `tables`) ใช้เว็บสร้าง QR ฟรีทั่วไปได้ แล้วพิมพ์ติดโต๊ะ

## แก้เมนูชั่วคราว (ก่อนมีหน้าแอดมินในเฟส 3)
Supabase > **Table Editor > menu_items** แก้ชื่อ ราคา รูป (`image_url` ใส่ลิงก์รูป) หรือติ๊ก `available` ออกเมื่อของหมด
ตัวเลือกเมนูอยู่ในคอลัมน์ `options` (ดูตัวอย่างในตอนท้ายของ `schema.sql`)

## โครงไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `schema.sql` | โครงฐานข้อมูล สิทธิ์ความปลอดภัย และฟังก์ชันสร้างออเดอร์ |
| `common.js` | โค้ดที่ใช้ร่วมกัน (ตะกร้า, แสดงเมนู, หน้าต่างเลือกตัวเลือก) |
| `order.html/.js` | หน้าลูกค้า |
| `staff.html/.js` | หน้าร้าน |
| `config.js` | ค่าเชื่อมต่อ Supabase |
